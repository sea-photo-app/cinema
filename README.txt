BEACH CINEMA — ДЕМО-ПРОЕКТ (Firebase Firestore)

Как запустить:
1. Распакуйте ZIP.
2. Откройте index.html в Chrome или Edge.
3. Для админки откройте admin.html.

Демо-доступ:
Логин: admin
Пароль: 12345

Возможности:
- Главная
- Афиша
- Бронирование одинаковых обычных мест
- Объявления
- Админ-панель
- Добавление/удаление фильмов
- Добавление/удаление объявлений
- Просмотр бронирований
- Расчёт выручки
- Отчёт по фильмам
- QR-сканер билетов

ХРАНЕНИЕ ДАННЫХ:
Данные хранятся НЕ в localStorage, а в облаке — Firebase Firestore.
Это значит:
- Все страницы сайта видят одни и те же данные с любого устройства.
- Броня на странице booking.html сразу доступна в админке и наоборот.
- Николай/админ и сотрудники работают с одной базой.

FIREBASE ПРОЕКТ: sea-photo-center
- База данных: Firestore, регион eur3 (или тот, что выбран).
- Коллекции: movies, bookings, announcements, employees, siteContent, dailyReports.

ФАЙЛЫ ПРОЕКТА:
- js/firebase-config.js — конфигурация Firebase (НЕ меняйте, если не меняете проект).
- js/data.js — слой данных (все операции с Firestore).
- js/app.js — логика приложения.

ПРАВИЛА БЕЗОПАСНОСТИ:
База открыта в тестовом режиме (читает/пишет любой). Для демо это нормально.
Для продакшена закройте Firestore правилами с аутентификацией.

ВАЖНО:
Первое открытие любой страницы создаёт пустые коллекции и добавляет
наборы по умолчанию (3 фильма, 2 объявления, 1 сотрудник seller/12345).
Управляя контентом в админке, вы меняете данные в облаке — это увидит каждый.
