# Безопасность

В этой версии удалены подсказки с демо-логином/паролем и кнопки скачивания/Wallet.

Важно: секреты нельзя надёжно "зашифровать" внутри HTML/JS — любой секрет, отправленный в браузер, пользователь может получить.
Для настоящей защиты секретные ключи должны находиться только на сервере в `.env`/secret storage.

QR теперь содержит код билета, а поиск билета выполняется по существующей записи. Добавлена нормализация кода и повторный запуск камеры без перезагрузки страницы.

Для production:
- HTTPS для камеры;
- серверная БД;
- хеширование паролей (bcrypt/argon2);
- серверная авторизация и роли;
- rate limiting;
- не хранить пароли/секреты в frontend.
